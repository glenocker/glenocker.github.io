# Garrett Lenocker | Mechanical Engineering Portfolio

Responsive, static engineering portfolio. The color palette uses the same blue accent (`#004AAD`) as the current one-page resume.

## Start

1. Extract this ZIP and keep the `engineering_portfolio` directory intact.
2. Open `engineering_portfolio/index.html` in a browser. The full site works offline.
3. To publish, upload all contents of `engineering_portfolio` (including the `assets` and `projects` folders) to a static web host such as Netlify or GitHub Pages. Your existing glenocker.com domain is **not** updated automatically.

## Features

- Responsive home page with project filters, education, experience and a dedicated resume preview section
- Projects dropdown in the site header linking directly to each of the eight featured project projects; includes `View all projects`
- Detailed project pages organized by goal, constraints, approach/contributions, result/evidence and lessons or next validation
- Original project CAD, photos and drawings from Baja SAE, solar oven, Kazvu Labs, Tacoma conversion, dirt bike maintenance and Porsche 944 work
- Enlarged image galleries on supported pages
- Updated resume at `assets/Garrett_Lenocker_Resume.pdf`, with `assets/resume-preview.webp` for the home page preview

## Site contents

- `index.html`: homepage
- `projects/*.html`: project case-study pages
- `styles.css`: design system and responsive styles
- `main.js`: mobile navigation, project dropdown, filters and image lightbox
- `assets/`: resume PDF, thumbnail, photographs, CAD images and illustrations

## Publishing note

Before making a public version of the site, verify which Kazvu Labs images and design details are approved to share. Some projects explicitly identify ongoing or conceptual work rather than implying completed tests or fabricated hardware.
